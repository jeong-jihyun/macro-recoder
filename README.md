# 🎬 PC 매크로 녹화/재생 프로그램

마우스 클릭, 마우스 이동, 키보드 입력을 순서와 시간 간격까지 그대로 기록했다가 나중에 똑같이 재생해주는 도구입니다.
매크로는 이름을 붙여 여러 개 저장/불러오기 할 수 있고, 녹화 도중 화면 스크린샷도 찍어서 함께 기록할 수 있습니다.

## 🎯 주요 기능

| 기능 | 설명 |
|------|------|
| **매크로 녹화** | 마우스와 키보드의 모든 동작을 정확한 시간 간격과 함께 기록 |
| **매크로 재생** | 저장된 매크로를 선택해 자동으로 재생 |
| **스냅샷 기능** | 녹화 중 특정 시점의 화면을 이미지로 저장 |
| **다중 매크로 관리** | 여러 개의 매크로를 이름으로 구분해 저장/불러오기 |
| **비상 정지** | 재생 중 언제든 F6으로 즉시 중단 가능 |

---

## 🛠️ 사전 준비

### 필수 패키지 설치

```bash
pip install pynput pillow
```

- **pynput** : 마우스와 키보드 입출력 처리
- **pillow** : 스크린샷 캡처 (선택사항, 없으면 스냅샷 기능만 비활성화)

## 📖 사용법

### 프로그램 실행

```bash
python macro_recoder.py
```

프로그램이 시작되면 다음과 같은 메시지가 표시됩니다:

```
=======================================================
PC 매크로 녹화/재생 프로그램 (스냅샷 지원)
F9:녹화시작/정지  F7:스냅샷(녹화중)  F10:재생  F6:정지  ESC:종료
현재 저장된 매크로: macro1, macro2
=======================================================
```

---

## ⌨️ 단축키

| 단축키 | 기능 | 설명 |
|--------|------|------|
| **F9** | 녹화 시작/정지 | 토글 방식 (첫 번째 F9: 시작, 두 번째 F9: 정지) |
| **F7** | 스냅샷 | 녹화 중에만 동작 - 현재 화면을 이미지로 저장 |
| **F10** | 매크로 재생 | 저장된 매크로 목록을 보여주고 선택해 재생 |
| **F6** | 재생 중지 | 재생 중인 매크로를 즉시 멈춤 |
| **ESC** | 프로그램 종료 | 프로그램 완전히 종료 |

## 📂 파일 구조

### 저장 위치

```
프로젝트 폴더/
├── macro_recoder.py           (메인 프로그램)
├── macros/                    (매크로 저장 폴더)
│   ├── my_macro.json          (매크로 데이터)
│   ├── my_macro_snapshots/    (스냅샷 이미지 폴더)
│   │   ├── snap_0001.png
│   │   ├── snap_0002.png
│   │   └── ...
│   └── other_macro.json
└── README.md
```

### JSON 매크로 데이터 형식

```json
[
  {
    "type": "move",
    "time": 0.5,
    "x": 500,
    "y": 300
  },
  {
    "type": "click",
    "time": 1.2,
    "x": 500,
    "y": 300,
    "button": "Button.left",
    "pressed": true
  },
  {
    "type": "key_press",
    "time": 2.0,
    "key": "a"
  },
  {
    "type": "snapshot",
    "time": 3.5,
    "file": "macros/my_macro_snapshots/snap_0001.png"
  }
]
```

**이벤트 타입:**
- `move` : 마우스 이동 (x, y 좌표)
- `click` : 마우스 클릭 (위치, 버튼, 누름/떨어짐)
- `scroll` : 마우스 스크롤 (dx, dy)
- `key_press` : 키 눌림
- `key_release` : 키 떨어짐
- `snapshot` : 스크린샷 (파일 경로)

## 🔄 동작 흐름

### 녹화 프로세스

```
F9 (시작) 
  ↓
마우스/키보드 리스너 활성화
  ↓
모든 동작이 자동 기록
  ↓
F7 (선택사항: 스냅샷 저장)
  ↓
F9 (정지)
  ↓
매크로 이름 입력 (기본값: "last")
  ↓
JSON 파일 저장 + 스냅샷 폴더 생성 완료
```

### 재생 프로세스

```
F10 (재생)
  ↓
저장된 매크로 목록 표시
  ↓
재생할 매크로 이름 입력
  ↓
JSON 로드 및 이벤트 순회
  ↓
각 이벤트 간 정확한 시간 간격만큼 대기
  ↓
마우스/키보드 자동 동작 재현
  ↓
재생 완료 또는 F6으로 중단
```

## 💡 예제

### 예제 1: 간단한 반복 작업 자동화

마우스로 특정 버튼을 클릭하고 텍스트를 입력하는 작업을 자동화하고 싶다면:

1. **F9 누르기** (녹화 시작)
2. 마우스로 버튼 클릭
3. 키보드로 텍스트 입력
4. **F9 누르기** (녹화 종료)
5. 이름 입력: `button_click_task`
6. 나중에 **F10** → `button_click_task` 선택 → 자동 재생! ✅

### 예제 2: 스냅샷과 함께 녹화

현재 화면이 어떤 상태에서 작업이 일어나는지 기록하고 싶다면:

1. **F9 누르기** (녹화 시작)
2. 작업 수행
3. 특정 시점에 **F7 누르기** (스냅샷 저장)
4. 계속 작업
5. **F9 누르기** (녹화 종료)
6. 이름 입력: `task_with_snapshot`
7. `macros/task_with_snapshot_snapshots/` 폴더에 이미지 저장됨 ✅

## ⚠️ 주의사항

- **시스템 단축키 충돌** : F9, F7, F10, F6, ESC가 다른 프로그램에서 사용 중이면 충돌할 수 있습니다.
- **절대 경로** : 마우스 좌표는 절대 좌표이므로 화면 해상도가 바뀌면 재생 위치가 달라질 수 있습니다.
- **시간 간격** : 매우 빠른 동작의 경우 시스템 성능에 따라 약간의 오차가 발생할 수 있습니다.
- **pillow 미설치** : pillow가 없어도 프로그램은 실행되지만 스냅샷 기능만 비활성화됩니다.

## 🛠️ 점검 내역 (2026-10)

| 구분 | 문제 | 수정 내용 |
| --- | --- | --- |
| 스냅샷 오류 | 스냅샷 폴더가 "녹화를 끝낸 뒤"에야 정해지는데 F7은 녹화 중에 쓰이므로, 프로그램을 처음 켜고 첫 녹화에서 F7을 누르면 폴더가 없어(`None`) 오류가 나고, 두 번째 녹화부터는 **이전 매크로의 스냅샷 폴더**에 저장됨 | 녹화 시작 때 임시 폴더(`macros/_recording_snapshots`)를 만들어 거기에 저장하고, 이름을 입력해 저장할 때 `<이름>_snapshots`로 옮기면서 JSON의 `file` 경로도 함께 맞춤. 같은 이름으로 다시 녹화하면 이전 스냅샷을 대체 |
| 안내 문구 | 파일 맨 위 설명이 `macro_recorder.py`로 되어 있어 실제 파일명(`macro_recoder.py`)과 다름 | 실제 이름으로 수정 |
| README | 기술 스택에 `keyboard`, `mouse` 라이브러리가 있으나 코드에서 쓰지 않음 | 삭제 (실제로는 `pynput`만 사용) |
| 저장소 관리 | 녹화 결과(`macros/`)가 저장소에 올라갈 수 있음 | `.gitignore` 추가 |

### 확인한 것과 못한 것

- 확인함: 키보드·마우스·화면 라이브러리를 가짜 모듈로 바꿔 녹화 → 스냅샷 → 저장 흐름을 실행했습니다. 스냅샷 2장이 `macros/demo_snapshots/`로 옮겨지고 JSON 경로가 일치하며, 같은 이름 재녹화 시 이전 스냅샷이 대체되고, 스냅샷이 없어도 폴더가 만들어지는 것을 확인했습니다.
- **확인하지 못함:** 이 작업 환경에는 화면과 입력 장치가 없어 실제 마우스·키보드 녹화와 재생은 해 보지 못했습니다.
